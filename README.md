# 2ndScan website

The website for [2ndScan](https://2ndscan.com), a free, independent, not-for-profit project that teaches practical critical thinking: take a second look.

The site is plain HTML and CSS, hosted free on GitHub Pages from the `main` branch.

## Files

- `index.html`: the home page
- `404.html`: the "page not found" page
- `assets/style.css`: colours, fonts and layout
- `CNAME`: tells GitHub Pages to serve the site at 2ndscan.com (don't delete it)
- `.nojekyll`: tells GitHub to publish the files as they are
- `robots.txt`: lets search engines index the site

## Making a change

Ask Claude Code to edit the page and push the change, or edit a file directly on github.com and click **Commit changes**. The live site updates within a minute or two.
